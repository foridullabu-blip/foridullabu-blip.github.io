# Md Foridul Islam Labu — academic website

Personal academic website: education research on inclusive education and education policy in Bangladesh and the Global South.

- `index.html` — the whole site (one page)
- `portrait.jpg` — profile photo
- `cv.pdf` — public CV (no phone number or referee contacts)
- `404.html` — sends old or broken links back to the homepage
- `.nojekyll` — tells GitHub Pages to serve the files as they are

To update the CV, replace `cv.pdf` with a new file of the same name.
